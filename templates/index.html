System Capabilities

Eye Closure Detection

Monitors Eye Aspect Ratio (EAR) in real time. Triggers alert when eyes remain closed for ≥ 20 consecutive frames.

EAR Algorithm

Yawn Detection

Calculates Mouth Aspect Ratio (MAR) from MediaPipe landmarks. Detects persistent yawning as an early drowsiness indicator.

MAR Algorithm

Head Pose Estimation

Uses PnP solver to compute pitch, yaw, and roll angles. Detects head nodding and looking away from the road.

OpenCV solvePnP

Phone Detection

YOLOv8 object detector identifies mobile phone usage in real time with configurable confidence threshold.

YOLOv8

Audio Alert System

Multi-channel alerts via audio file playback and text-to-speech. Cooldown control prevents alert fatigue.

pygame + pyttsx3

Detection Logging

Every detection event is stored in SQLite with EAR, MAR, head angles, timestamps, and auto-captured screenshots.

SQLite + SQLAlchemy
